# Original demo media

The three SVG landscapes are original procedural vector illustrations made for PaperPlay, covered by the project license. The MP4 clips use a gentle zoom of these illustrations and original synthesized sine-wave chords. They contain no third-party footage, music or network requests.

Each clip is 12 seconds, 960×540, H.264/AAC. The website plays these real local assets through a shared HTML video element; imported user files use browser object URLs and are not uploaded. The performance demo measures browser animation timing, not desktop process or GPU usage.
