一些你可能想知道的事

需要运行 Wallpaper Engine 吗？

不需要。PaperPlay 直接读取本机已经下载的视频订阅。下载或更新订阅仍由 Steam / Wallpaper Engine 完成。

所有类型的壁纸都能播放吗？

扫描仅支持 project.json 中标记为 video 的项目。场景（scene）、网页（web）与应用（application）壁纸不作为视频播放。

移出媒体库会删除原文件吗？

不会。PaperPlay 只移除自己的记录，不删除媒体文件，也不取消 Steam 订阅。重新扫描时订阅项目会重新出现。

如何隐藏列表中的预览画面？

在设置、订阅库或本地媒体页开启「模糊预览」。这些开关即时同步，封面会产生模糊效果，重启后也会记住选择。

为什么便携版不能只复制 EXE？

Flutter 与播放内核需要同目录的 DLL、data 与其他资源。请保留完整解压目录。每个 Release 均提供 SHA-256 校验文件与构建信息。
